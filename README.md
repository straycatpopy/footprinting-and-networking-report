# footprinting-and-networking-report
Footprinting & Network Scanning


This project documents practical cybersecurity exercises involving footprinting, reconnaissance, and network scanning as part of my cybersecurity training at Networkwalks.

Tools Used
Kali Linux
WHOIS
WhatWeb
Nslookup
Curl
Wafw00f
DNSRecon
Nmap

Activities Performed
Footprinting: Collected publicly available information about networkwalks.com.
DNS Enumeration: Identified DNS records, name servers, mail servers, and other DNS information.
WAF Detection: Identified the web application firewall protecting the website.
Network Scanning: Used Nmap to discover active hosts on my local network.
Key Findings
Website IP: 192.232.216.135
Web Server: Apache
CMS: WordPress
WAF: ModSecurity (SpiderLabs)
Active local network hosts: 2
Network device identified: Huawei router
Purpose
The purpose of this project was to demonstrate practical knowledge of information gathering,DNS enumeration,website fingerprinting,and network discovery.
